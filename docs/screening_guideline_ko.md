# 이상치 해석 가이드라인 (reference)

> 출처: `outlier_reference_guidelines.csv` 를 마크다운으로 정리한 문서.  
> 목적: 실운항 시계열에서 **물리·통계·운항맥락** 기준으로 이상치를 정의하고, 학습 데이터 정제에 사용한다.
> **현행 v1.4 (2026-11-13)**: 프리징(고착) 판정의 30분 기준을 모두 **120분**으로 바꾸고, SPEED(SOG) 고착은 위·경도 이동속도로 먼저 검증한다(§5.11). 아래 표와 §5의 값은 v1.4 기준이며, 원본 CSV의 30분 값은 v1.3 이전 기준이다. 기계 적용 규칙은 `screening_rules_v1.4.yaml`.

## 1. 판정 축 (4가지)

| # | 축 | 의미 |
|---|----|------|
| 1 | **물리값 정적 한계 (Static Min/Max)** | 물리적으로 불가능한 절대 범위 이탈 |
| 2 | **스파이크 노이즈 (Spike / Outlier)** | 단발성 극단값·센티널(invalid) 패턴 |
| 3 | **시계열 동적 한계 (Dynamic / Delta)** | 단위시간당 변화량(Δ)이 비정상적으로 큼 |
| 4 | **프리징 및 정박 판별 (Freezing / Delta=0)** | 운항 중인데 값이 장시간 고정(Δ≈0)되거나, 정박·접안 구간으로 학습에서 제외 |

추가 축:
- **관계 이상치**: 물리적으로 연결된 변수끼리 정합성이 깨질 때
- **정박·접안 구간 제거**: 행(구간) 단위로 학습 데이터에서 제외

| `v10` | O | 위도방향 절대풍속 | m/s | 고정 상·하한 이상치 기준 없음 (Wind Speed = √(u10²+v10²)로 실제 풍속 계산 후 별도 검증) | — | — | — |

### 9. 정박·접안 구간 제거

#### 정박/접안 판정

- **설명**: 정박·계류 구간 학습데이터 제외
- **정적 한계**: LAT/LON 위치가 육지·부두 경계 또는 매우 인접
- **프리징/정박·관계 판정**: AND 60분 동안 SOG ≤ 0.5 knots 비율 ≥ 90% AND 60분 동안 LAT/LON 이동 직경 ≤ 100m → 접안·계류 구간으로 판단, 학습 데이터에서 제외

### 10. 관계 이상치

#### DISPLACEMENT ↔ DEADWEIGHT

- **설명**: 선박 중량 관계 정합성
- **프리징/정박·관계 판정**: DISPLACEMENT − DEADWEIGHT ≈ Lightweight. **[확정]** §5.6 — \|LW − median_LW\| > max(5000 t, 0.08×\|median_LW\|)

#### ME SHAFT POWER ↔ ME RPM ↔ ME SHAFT TORQUE

- **설명**: 동력-회전수-토크 물리관계 정합성
- **프리징/정박·관계 판정**: POWER = TORQUE × π × RPM / 30. **[확정]** §5.7 — 선박별 보정계수 후 상대오차 > 50%

#### FWD DRAFT ↔ AFT DRAFT ↔ TRIM

- **설명**: 흘수-트림 정합성
- **프리징/정박·관계 판정**: TRIM ≈ AFT − FWD. **[확정]** §5.8 — \|TRIM − TRIM_calc\| > 1.0 m (부호는 선박별로 확인)

## 3. 규칙 요약 (구현 관점)

### 3.1 공통 운항 조건
- 여러 프리징 규칙에서 **운항 중**을 `SPEED(SOG) ≥ 5.0 knots`로 정의.
- 정박·접안 제외는 별도 AND 조건(위치·SOG·이동직경).

### 3.2 정적 한계가 명확한 핵심 타깃
| 컬럼 | 이상치 조건 (정적) |
|------|-------------------|
| ME FO FLOW | `< 0` 또는 `> 16,000` L/hour (**65,5xx 대역** = invalid/sentinel. 최빈 65,525; 65,534는 0.32%뿐 — 2026-10-04 정정) |
| ME SHAFT POWER | `< 0` 또는 `> 60,000` kW |
| SPEED(SOG) | `< 0` 또는 `> 27.0` kn |
| SPEED(STW) | `< -5.0` 또는 `> 25.5` kn |
| HEADING | `< 0` 또는 `≥ 360` deg |
| RUDDER ANGLE | 최종 제거 기준 `±40°` 밖 |
| FORE/AFT DRAFT Noon | `≤ 0` 또는 `> 16.55` m |

### 3.3 Noon Report 예외
- FORE/AFT/Trim Noon: **24시간 Δ=0 은 정상** (Noon 보고 특성). 다른 센서의 “운항 중 프리징=이상”과 반대.

### 3.4 정규화(삭제 아님)
- `WIND ANGLE(T)`, `mwd`: `% 360`으로 `0° ≤ θ < 360°` 정규화. 이상치 삭제가 아님.

### 3.5 외부 데이터 의존 (현재 레포 기준)
- `SEA WATER TEMP` ↔ OISST, `WATER DEPTH-M` ↔ ETOPO: **이 저장소에 매칭 코드 없음** → 외부 격자 준비 전까지는 **정적/동적/프리징 규칙만** 적용. OISST·ETOPO 규칙은 “보류(외부의존)”.
- `DISPLACEMENT`/`DEADWEIGHT`: 공식 DWT 상한은 데이터 max와 일치(Ship A 232,606 t, Ship H ≈229,039 t). LIGHTSHIP은 제원표 대신 **선박별 (DISPLACEMENT−DEADWEIGHT) 중앙값**으로 추정 가능(Ship A·Ship C ≈63,003 t, Ship H ≈63,845 t).

### 3.6 Importance
- reference 표의 O/△/X는 `dataset/kr_parameter_explanation.csv`의 Importance와 **동일** (추가된 정박 판정·관계식 행만 kr에 없음).

## 5. 불확실 항목 → 데이터 기반 확정

아래는 CSV만으로는 모호했던 정의를 선별된 자료로 확인한 뒤 **구현용으로 고정**한 내용이다.

### 5.1 FWD/AFT DRAFT 동적 스파이크 (robust threshold)

| 항목 | 확정 |
|------|------|
| 의미 | threshold는 **절대편차(m)**: \|현재흘수 − 전후 15분 로컬 중앙값\| |
| 로컬 중앙값 | 샘플간격 ≈1분 가정, `rolling(window=31, center=True)` 중앙값 |
| 선박별 임계 | 운항(SOG≥5) 구간의 \|dev\| 분포에서 **P99.9** (가이드 문구의 3.25–4.40m / 0.95–1.38m와 실측 P99.9–P99.99가 부합) |
| 회복 조건 | 스파이크로 보려면 ±5분 지점 흘수가 서로 비슷 (예: \|xₜ₋₅ − xₜ₊₅\| < 1.0 m) → “찍고 복귀” 패턴 |
| 판정 | SOG≥5 AND \|dev\| > thr_vessel AND 회복 조건 → 해당 시각 셀 이상치 |

### 5.2 TRIM (및 Trim Noon) gap cutoff

| 항목 | 확정 |
|------|------|
| 단위 | **선박별** TRIM 관측값 전체 분포 |
| 절차 | (1) 하위 1%·상위 1% tail을 각각 정렬 (2) 인접값 차이(gap) ≥ **1.0 m**인 첫/끝 큰 틈을 찾음 (3) `cutoff = (극단측 값 + 정상측 값) / 2` (4) 하한: TRIM < cutoff_low, 상한: TRIM > cutoff_high → 이상치 |
| 검증 예 | Ship C 상한 cutoff≈10.56 (극단 14건), Ship H·Ship L은 ±15 m대 cutoff로 수백 건 규모 극단 클러스터 분리 |
| 비고 | TRIM 결측률이 높음(선박별 약 35–48%만 non-null). 결측은 이상치가 아님 |

### 5.3 MID DRAFT 프리징

| 항목 | 확정 |
|------|------|
| Δ=0 해석 | **보고값이 숫자 그대로 120분 연속 동일** (stuck, v1.4; 이전 30분). “거의 안 변함(0.1m)”으로 완화하지 **않음** |
| 이유 | 운항 중 30분 range\<0.1 m 비율이 수 %라 완화 시 정상 평형항해를 대량 오탐. exact freeze 발생률은 표본상 ≈0% → 드물게 stuck 센서만 잡는 안전망으로 유지 |
| 적용 | SOG≥5 AND 120분 window max=min (non-null) → 이상치 |

### 5.4 위치(위·경도) 프리징 수치

| 항목 | 확정 |
|------|------|
| 이동거리 | UTC 기준 t → t+120min Haversine (m) (v1.4; 이전 30분) |
| 임계 | SOG(t)≥5 이고 이동거리 **≤ 200 m** → 위치 프리징 후보 |
| 근거 | 정상 운항 30분 이동의 p0.1이 약 1.7–2.2 km(120분은 그 약 4배); ≤200 m은 사실상 GPS 정지 수준(발생 극소) |
| 비고 | Lat/Lon을 따로 두 번 지우지 말고 **위치 한 마스크**로 적용 |

### 5.5 WATER DEPTH ↔ ETOPO / SEA WATER TEMP ↔ OISST

| 항목 | 확정 |
|------|------|
| 상태 | **보류(외부의존)** — 이 저장소에 ETOPO·OISST 매칭 파이프라인 없음 |
| 당장 적용 | WATER DEPTH: `≤ 0` 정적 + 운항 중 120분 값 고정 프리징. SEA WATER TEMP: \|Δ\|≥3°C/min 동적 + 12h 동일값 프리징 |
| 추후 | 외부 격자 붙이면 CSV 원문 규칙(OISST +8°C, ETOPO bias P99.9) 활성화 |

### 5.6 DISPLACEMENT ↔ DEADWEIGHT (Lightweight)

| 항목 | 확정 |
|------|------|
| 정의 | `LW = DISPLACEMENT − DEADWEIGHT` |
| 선박별 정상 | LW 중앙값이 거의 상수(Ship A≈63,003 t, Ship H≈63,845 t), corr(Disp,DWT)≈0.998 |
| 이상치 | 양쪽 non-null일 때 \|LW − median_LW(vessel)\| > **max(5,000 t, 0.08×\|median_LW\|)** → 관계 이상치 (양쪽 셀 또는 해당 시각 플래그) |
| DWT 정적 상한 | Ship A계열 >232,606 t, Ship H계열 >229,039 t (가이드 수치 유지; 실측 max와 일치) |

### 5.7 ME POWER ↔ RPM ↔ TORQUE

| 항목 | 확정 |
|------|------|
| 식 | `P_calc = TORQUE(kNm) × π × RPM / 30` (kW) |
| 이상치 | RPM·TORQUE·POWER 모두 non-null, \|RPM\|>1 일 때 상대오차 \|P_calc − POWER\| / max(\|POWER\|,1) > **0.50** (50%) 이면 관계 이상치. 선박별 스케일 이상 시 median 보정계수 α=median(POWER/P_calc)를 먼저 적합 후 \|α P_calc − POWER\|로 판정 |
| 비고 | 토크 단위/스케일이 선박마다 다를 수 있어 **1차 계수 보정 후** 적용 |

### 5.8 FWD/AFT DRAFT ↔ TRIM

| 항목 | 확정 |
|------|------|
| 식 | `TRIM_calc = AFT DRAFT − FWD DRAFT` |
| 부호 | 실데이터 TRIM 중앙값은 선박별 소폭 +/−. **\|TRIM − TRIM_calc\|** 로 크기만 보고, 부호가 전 선박에서 반대로 보이면 `TRIM_calc = FWD − AFT`로 전환 |
| 이상치 | 세 변수 non-null이고 \|TRIM − TRIM_calc\| > **1.0 m** → 관계 이상치 |

### 5.9 정박·접안 구간 제거

| 항목 | 확정 |
|------|------|
| 판정 단위 | 셀이 아니라 **시간 구간(행 집합) 제외** |
| 조건(AND) | (1) 육지/부두 인접은 지도·수심 보조가 없으면 당분간 생략 가능 (2) 직전 60분 SOG≤0.5 kn 비율 ≥90% (3) 60분 LAT/LON 이동 직경 ≤100 m |
| 직경 | 60분 window 내 점들의 최대 Haversine pairwise (또는 lat/lon bounding 대각선) ≤100 m |

### 5.10 year_one(23피처) 적용 범위

첫해 자료에 없는 컬럼(MID DRAFT, DISPLACEMENT, WATER DEPTH-M, ME LOAD 등) 규칙은 **screened/원본 단계** 또는 해당 컬럼이 있는 데이터셋에만 적용. year_one 정제 시에는 존재하는 컬럼 규칙만 사용.

### 5.11 고착 판정 개정 (v1.4, 2026-11-13)

| 항목 | 확정 |
|------|------|
| 배경 | 30분 동일값 기준은 정상 정속 항해를 고착으로 판정함. 예: SOG가 12.3 kn으로 95분 동안 같은 구간은 주변 기록과 분포상 정상 범위이며 실제 정속 항해와 구별되지 않음 |
| 기간 | 고착 판정 목록에서 30분이던 항목을 모두 **120분**으로 변경: HEADING, SPEED(SOG), SPEED(STW), MID(P)·MID(S) DRAFT, WIND ANGLE(R), WATER DEPTH-M(동일값), ME LOAD, ME RPM, ME RPM(INT), ME SHAFT POWER, ME FO FLOW, WIND SPEED(R)(0 근처 값 지속), 위치 프리징(이동거리 기간). 30분이 아니던 RUDDER ANGLE 120분, SEA WATER TEMP 12시간, ER TEMP 6시간은 그대로 |
